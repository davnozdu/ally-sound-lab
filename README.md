# Ally Sound Lab

[Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader) plugin for the ROG Ally / Xbox Ally X on CachyOS. Real-time virtual 7.1 / stereo-to-3D upmix with a neural voice separator for headphones, the built-in speakers and XREAL glasses, with per-app profiles, in Game Mode.

Плагин Decky для ROG Ally на CachyOS. Перехватывает весь звук игр и фильмов в игровом режиме, делает из него объёмный звук для наушников, встроенных динамиков или очков XREAL и отдаёт на текущий аудиовыход.

## Что делает

Плагин создаёт виртуальный выход 7.1. Игры и плееры видят 7.1 и отдают настоящие каналы. Плагин расставляет их как виртуальные динамики и сводит под реальное устройство вывода (см. «Типы выхода»).

- **Источник 5.1/7.1.** Каждый канал ставится в свою точку: фронт ±30°, центр 0°, боковые ±100°, тыловые ±145°. Тылы 5.1 ставятся под ±100°.
- **Источник стерео.** Типичный случай — дублированная дорожка фильма. Объём строится из двух каналов: голос уходит в центр, остальное остаётся спереди, а эмбиент с задержкой разносится в боковые и тыловые виртуальные динамики. Голос отделяет либо нейросеть [StemgenRT](https://github.com/sweetspotsoundsystem/stemgen-rt), либо простая матрица без нейросети (переключатель «Нейросеть для стерео»).
- **Кривой дубляж в 5.1/7.1 (профиль «Кино»).** Дешёвый дубляж копирует голос во все каналы, и объём схлопывается. Один прогон StemgenRT по сведению всех каналов даёт эталон голоса. Скользящая подгонка методом наименьших квадратов (~0,25 с) находит долю голоса в каждом канале, вычитает её там и ставит голос только в центр. На синтетическом тесте во фронте и тылах остаётся ~5% голоса. В «Игре» голоса на 5.1 не трогаются: они позиционные.
- **Определение источника** идёт на лету по энергии каналов. PipeWire не растягивает стерео на 7.1, поэтому определение надёжное.

### Профили

| | Игра | Кино |
|---|---|---|
| Диалоги (центр) | 0 дБ | +5 дБ |
| Комната | RT60 0,22 с, тихая | RT60 0,40 с |
| Компрессия громких сцен | нет | 3:1 от −30 dBFS |

Громкость профилей выровнена с оригиналом. «Сравнить с оригиналом» временно отключает обработку для честного A/B.

### Типы выхода

Тип определяется автоматически: по порту встроенной карты (динамик или 3,5 мм), по типу Bluetooth-устройства, по имени (XREAL), по HDMI. Его можно переопределить в меню, выбор запоминается для каждого устройства.

- **Наушники** — бинауральный рендер через HRTF (KU100) с синтетической комнатой.
- **Динамики** — HRTF на открытых динамиках не работает, поэтому здесь виртуализатор:
  - голос моно в центре;
  - тылы получают дополнительную боковую составляющую, а их общая часть приходит на 12 мс позже и не сливается с фронтом;
  - подавление перекрёстных помех по схеме [x20-speaker-dsp](https://github.com/ismailkose/x20-speaker-dsp) (MIT): только боковой сигнал в полосе 250 Гц – 6 кГц, задержки 75/150 мкс, веса 0,55/0,3025. Сцена шире корпуса, центр не трогается;
  - маленькая комната;
  - на встроенных динамиках Ally применяется коррекция из CachyOS (`/usr/share/cachyos-handheld/rog-ally/game.wav`). Штатный filter-chain пакета на Ally X нацелен на несуществующий PCI-адрес и звук не корректирует.
- **Очки (XREAL)** — динамики стоят у самых ушей, поэтому используется HRTF и подъём басов на 2 дБ.

### Динамика

Цепочка: выравниватель → быстрый компрессор → ограничитель с упреждением. Включается в «Кино» на любом устройстве и всегда на динамиках и очках. В «Игре» на наушниках остаётся только ограничитель.

- **Выравниватель** (по x20-speaker-dsp): цель −20 LUFS, ±12 дБ, нарастание за 10 с, спад за 8 с, ниже −50 LUFS не усиливает. Тихие диалоги и громкие сцены выравниваются без «качания».
- **Компрессор:** −14 дБ, 3:1, мягкое колено 6 дБ, атака 3 мс, отпускание 120 мс, по RMS, каналы связаны.
- **Ограничитель:** потолок 0,89, упреждение на один блок (2,9 мс).

«Сравнить с оригиналом» сохраняет ту же динамику и сравнивает только пространственную часть.

Многополосный ограничитель x20-speaker-dsp не перенесён: его значения сняты с заводской настройки X20 (RC74XA), а у Ally X (RC73XA) другие динамики и усилители.

### Громкость

Ползунок громкости Steam управляет выходом по умолчанию, то есть виртуальным выходом плагина. Поэтому при включении громкость реального устройства переносится на виртуальный выход, а само устройство работает на 100%. При смене устройства и при выключении громкость возвращается. Все режимы выровнены по громкости с оригиналом (в пределах 1–2 дБ), так что «Сравнить с оригиналом» — честное A/B.

### Профиль для каждого приложения

Фронтенд следит за активным приложением Steam (`RegisterForAppLifetimeNotifications` и `SteamUIStore.MainRunningApp`), в том числе за неSteam-ярлыками. Когда игра запущена, профиль и нейросеть из меню сохраняются для неё. Пункт «Как по умолчанию» удаляет запись, и приложение снова следует профилю по умолчанию, который настраивается без запущенных игр. Профиль переключается без перезапуска звука.

### Нагрузка (Ryzen Z2 Extreme, блок 128 сэмплов = 2,9 мс)

- 5.1/7.1 без нейросети — около 0,3 мс;
- стерео с матрицей — около 0,6 мс;
- стерео со StemgenRT или 5.1 с исправлением дубляжа — около 1,0–1,35 мс. Модель (~0,9 мс) считается в отдельном потоке конвейером, на один блок позади.
- На тишине модель не запускается.

## Маршрутизация

1. `audio_worker.py live <game|movie>` создаёт null sink `ally_sound_lab` (7.1, 44,1 кГц), делает его выходом по умолчанию и переносит на него уже играющие приложения.
2. `parec` читает монитор блоками по 128 сэмплов, `spatial.py` превращает их в бинауральное стерео, `pacat` отдаёт его на реальное устройство. Профиль, нейросеть и сравнение переключаются JSON-командами через stdin воркера.
3. Новое устройство (Bluetooth, USB, HDMI) или выбранный выход подхватываются на лету. Если устройство пропало, звук уходит на устройство с наивысшим приоритетом.
4. При выключении прежний выход по умолчанию восстанавливается, а виртуальный удаляется.

Виртуальные выходы (filter-chain, null sink) никогда не выбираются целью: их выход идёт в выход по умолчанию, то есть в плагин, и звук пошёл бы по кругу.

`main.py` хранит настройки в `~/.local/share/ally-sound-npu/settings.json`, поднимает обработку после перезагрузки, перезапускает упавший воркер (до 5 раз за 2 минуты) и пишет его stderr в `worker.log`.

## Установка

Нужны: Decky Loader, `uv` (`sudo pacman -S uv`), `curl`, `sha256sum`, PipeWire с `pactl`/`parec`/`pacat`. Коррекция динамиков Ally берётся из пакета `cachyos-handheld`, если он установлен.

Без `install-runtime.sh` плагин покажет «Модели не установлены».

На приставке, от обычного пользователя:

```bash
./install-runtime.sh          # venv (Python 3.13) + модели в ~/.local/share/ally-sound-npu
```

Сборка фронтенда:

```bash
npm ci
npm run build                 # dist/index.js
```

Скопируй `plugin.json`, `package.json`, `main.py`, `audio_worker.py`, `spatial.py` и `dist/index.js` в `~/homebrew/plugins/Ally Sound Lab/`, затем выполни `sudo systemctl restart plugin_loader`.

Офлайн-прогон файла через ту же цепочку с замером времени на блок:

```bash
~/.local/share/ally-sound-npu/.venv/bin/python tools/offline_render.py film.mkv out.wav --profile movie [--device headphones|speakers|glasses] [--correction game.wav] [--no-model] [--bypass]
```

## Заметки

- Decky собран PyInstaller-ом и выставляет `LD_LIBRARY_PATH` на свою `libstdc++`, с которой системный mpv падает. Поэтому `main.py` очищает `LD_*` у дочерних процессов.
- `pactl` в PipeWire не отдаёт `index` в `--format=json list modules`, поэтому модуль ищется через `pactl list short modules`.
- Игры выбирают число каналов при запуске, поэтому обработку нужно включать до запуска игры. С профилем по умолчанию она включена всегда.
